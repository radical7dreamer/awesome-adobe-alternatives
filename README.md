## Photo Editing

Alternatives to Photoshop and Canva photo tools.

- [Photoden](https://photoden.app) - Browser image editor for raster and vector work that runs offline.
- [GIMP](https://www.gimp.org) - Open source desktop image editor with layers, masks and filters.
- [PhotoGIMP](https://github.com/Diolinux/PhotoGIMP) - A patch that gives GIMP a Photoshop-like layout and shortcuts.
- [Photopea](https://photopea.com) - Browser editor that opens PSD, XCF and Sketch files.
- [Pinta](https://www.pinta-project.com) - Simple open source paint and image editor for Linux, Windows and macOS.
- [Paint.NET](https://www.getpaint.net) - Light Windows editor with layers and plugins.
- [Pixlr](https://pixlr.com) - Browser photo editor with a free tier.
- [Affinity](https://www.affinity.studio) - Desktop photo, vector and layout apps from Canva, free to use.
- [Pixelmator Pro](https://www.pixelmator.com/pro) - Mac image editor sold for a one time price.
- [Squoosh](https://squoosh.app) - Browser image compressor that converts between formats and compares the result side by side.
- [XnView MP](https://www.xnview.com/en/xnviewmp) - Desktop image browser and batch converter.
- [Kapwing](https://www.kapwing.com) - Browser design and video tool for quick social graphics, free tier with a watermark.

- [AI 만화 번역기](https://www.mangatranslate.com/ko/ai-manga-translator/) - 브라우저에서 만화 번역과 스튜디오용 온라인 편집을 지원하는 기업급 만화 리더이며, 무료 이용에 제한이 있고 유료 요금제를 제공합니다.

## Raw Photos and Lighting

Alternatives to Lightroom and Camera Raw.

- [Lightden](https://lightden.app) - Browser raw developer that never uploads your photos.
- [darktable](https://www.darktable.org) - Open source raw developer with a non-destructive pipeline and a lighttable view.
- [RawTherapee](https://www.rawtherapee.com) - Open source raw converter with detailed demosaic and colour controls.
- [ART](https://artraweditor.github.io) - A RawTherapee fork with a simpler interface.
- [RapidRAW](https://www.getrapidraw.com) - GPU accelerated raw editor for the desktop.
- [digiKam](https://www.digikam.org) - Photo manager with tagging, face recognition and basic raw editing.

## Drawing and Painting

Alternatives to Procreate and Photoshop's brush tools.

- [Sketchden](https://sketchden.app) - Browser painting app with pigment-style color mixing and radial menus. Works offline.
- [Krita](https://krita.org) - Open source painting program with a large brush engine, used by illustrators and comic artists.
- [MyPaint](https://mypaint.app) - Open source painting app with an infinite canvas and pressure brushes.
- [Kleki](https://kleki.com) - Browser painting tool with layers and a clean interface.
- [Tux Paint](https://tuxpaint.org) - Open source drawing program for children.
- [FireAlpaca](https://firealpaca.com) - Free desktop painting app with layers and comic tools.
- [MediBang Paint](https://medibangpaint.com) - Free painting and manga app for desktop and mobile.
- [Excalidraw](https://excalidraw.com) - Browser whiteboard for hand drawn diagrams.

## Pixel Art

- [Spritescape](https://spritescape.app) - Browser pixel art and sprite animation editor that uploads nothing.
- [Piskel](https://www.piskelapp.com) - Browser sprite editor with animation preview.
- [Pixelorama](https://orama-interactive.itch.io/pixelorama) - Open source pixel art editor made with Godot.
- [PixiEditor](https://pixieditor.net) - Open source pixel art and animation editor for Windows and Linux.
- [LibreSprite](https://libresprite.github.io) - Open source fork of an older Aseprite release.
- [Lospec Pixel Editor](https://apps.lospec.com/pixel-editor) - Browser pixel editor with a large palette library.
- [Aseprite](https://www.aseprite.org) - The standard desktop sprite editor. Paid, with source available to build yourself.

## Vector and Design

Alternatives to Illustrator, XD and Canva.

- [Vectorden](https://vectorden.app) - Offline vector editor that runs in the browser.
- [Inkscape](https://inkscape.org) - Open source vector editor built around SVG.
- [Graphite](https://graphite.rs) - Open source vector and raster editor with a node based workflow, still in development.
- [Boxy SVG](https://boxy-svg.com) - SVG editor for the browser and desktop.
- [Linearity Curve](https://www.linearity.io/curve) - Free vector editor, formerly Vectornator.
- [Penpot](https://penpot.app) - Open source design and prototyping tool, an alternative to Figma and XD.
- [SVGcode](https://svgco.de) - Browser tool that converts bitmap images to SVG.
- [VTracer](https://www.visioncortex.org/vtracer) - Open source image to vector converter that handles colour images.

## Video

Alternatives to Premiere Pro and CapCut.

- [Videoden](https://videoden.app) - Browser video editor with a timeline and motion graphics. Nothing is uploaded.
- [Kdenlive](https://kdenlive.org) - Open source multitrack editor with proxy editing and keyframes.
- [Shotcut](https://www.shotcut.org) - Open source editor for Windows, macOS and Linux.
- [OpenShot](https://www.openshot.org) - Open source editor aimed at beginners.
- [Olive](https://olivevideoeditor.org) - Open source node based editor, still in alpha.
- [Pitivi](https://www.pitivi.org) - Open source editor for the GNOME desktop.
- [DaVinci Resolve](https://www.blackmagicdesign.com/products/davinciresolve) - Professional editor, colour and audio suite with a free version.
- [Clipchamp](https://clipchamp.com) - Browser video editor from Microsoft with a free tier.
- [Blender](https://www.blender.org) - Open source 3D suite that includes a video sequence editor.
- [LosslessCut](https://github.com/mifi/lossless-cut) - Open source tool that trims and joins video without re-encoding.
- [HandBrake](https://handbrake.fr) - Open source video transcoder.
- [FFmpeg](https://ffmpeg.org) - Command line tool behind most video software.

## Audio

Alternatives to Audition.

- [Audioden](https://audioden.app) - Offline multitrack audio editor that runs in the browser.
- [Audacity](https://www.audacityteam.org) - Open source audio recorder and editor.
- [Tenacity](https://tenacityaudio.org) - Community fork of Audacity.
- [Ocenaudio](https://www.ocenaudio.com) - Free editor with real time effect previews.
- [Ardour](https://ardour.org) - Open source digital audio workstation.
- [LMMS](https://lmms.io) - Open source music production software.
- [REAPER](https://www.reaper.fm) - Low cost audio workstation with a long free evaluation.

## PDF

Alternatives to Acrobat.

- [PDFden](https://pdfden.app) - Merge, split, compress, convert and sign PDFs in the browser. Files never leave the device.
- [Stirling-PDF](https://www.stirlingpdf.com) - Open source PDF toolkit you can host yourself.
- [PDF Arranger](https://github.com/pdfarranger/pdfarranger) - Open source app to merge, split, rotate and reorder pages.
- [PDFtk](https://www.pdflabs.com/tools/pdftk-the-pdf-toolkit/) - Command line toolkit for merging, splitting and encrypting PDFs.
- [LibreOffice Draw](https://www.libreoffice.org/discover/draw/) - Opens PDFs for text and layout edits.
- [PDF24](https://www.pdf24.org) - Free online and desktop PDF tools.
- [PDFgear](https://www.pdfgear.com) - Free PDF editor and converter for Windows and Mac.
- [Sejda](https://www.sejda.com) - Browser PDF editor with a free daily limit.
- [EmbedPDF](https://app.embedpdf.com) - Browser based PDF viewer and editor.
- [SumatraPDF](https://www.sumatrapdfreader.org) - Fast open source PDF reader for Windows.
- [Okular](https://okular.kde.org) - Open source document viewer with annotations.
- [Zathura](https://pwmt.org/projects/zathura) - Keyboard driven document viewer.

## Page Layout

Alternatives to InDesign.

- [Scribus](https://www.scribus.net) - Open source desktop publishing with CMYK and PDF export.

## Animation and Motion

Alternatives to Animate and After Effects.

- [Glaxnimate](https://glaxnimate.mattbas.org) - Open source editor for vector animations and Lottie.
- [Rive](https://rive.app) - Browser tool for interactive animations, free tier.
- [Synfig Studio](https://www.synfig.org) - Open source 2D animation with vector tweening.
- [OpenToonz](https://opentoonz.github.io/e) - Open source 2D animation software used in studio production.
- [Tahoma2D](https://tahoma2d.org) - OpenToonz fork aimed at independent animators.
- [Pencil2D](https://www.pencil2d.org) - Simple open source 2D hand drawn animation.
- [Wick Editor](https://www.wickeditor.com) - Browser tool for drawn animation and small games.
- [Natron](https://natrongithub.github.io) - Open source node based compositor.
- [Jitter](https://jitter.video) - Browser motion design tool.
